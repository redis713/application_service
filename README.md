# Электронный сервис подачи заявок на обучение
### ГБУ ДПО «Учебно-методический центр по ГО, ЧС и ПБ Иркутской области»

Веб-сервис автоматизации приема и обработки заявок от организаций, предприятий и органов местного самоуправления на обучение специалистов по программам дополнительного профессионального образования (ДПО).

---

## 🚀 Основные возможности

1. **Многошаговый мастер подачи заявки**:
   - **Шаг 1**: Ввод реквизитов направляющей организации и данных слушателей (сведения для ФИС ФРДО, профильное образование по пожарной безопасности, выбор программ обучения, маски телефонов и СНИЛС).
   - **Шаг 2**: Мгновенная генерация официального печатного бланка заявления в формате Microsoft Word (`.docx`) по одному из 7 утвержденных шаблонов с заполнением всех реквизитов и таблицы слушателей.
   - **Шаг 3**: Загрузка скан-копии подписанного руководителем и заверенного печатью заявления (PDF, JPG, PNG, TIFF) и передача заявки в учебный отдел.

2. **Безопасный доступ без необходимости регистрации**:
   - Каждой заявке присваивается уникальный номер (например, `ГО-2026-0001`, `ПБ-2026-0002`) и криптографически стойкий секретный токен (`secret_token`).
   - Заявитель может вернуться к своей заявке по прямой ссылке, скорректировать данные на 1-м шаге, заново скачать обновленный документ или прикрепить скан позже.

3. **Внутренний портал для сотрудников (contractmaker.umcgochs.local)**:
   - **Реестр всех заявок**: сводная статистика (всего заявок, на проверке, черновики, в обработке, количество слушателей), поиск (по номеру заявки, организации, ИНН, ФИО исполнителя или слушателя), фильтры по статусу, направлению, форме обучения и наличию скана, пагинация.
   - **Детальная карточка заявки**: исчерпывающие реквизиты организации, данные руководителя и исполнителя, полный список слушателей со сведениями для ФИС ФРДО и пожарной безопасности, выбранными курсами и сроками.
   - **Скачивание и просмотр документов**: мгновенная генерация и скачивание официального бланка `.docx`, встроенный просмотр прикрепленного PDF/скана прямо в браузере и скачивание файла.
   - **Безопасная изоляция**: внешние запросы из интернета не имеют доступа к внутреннему разделу (HTTP 404), доступ осуществляется только через домен `contractmaker.umcgochs.local` во внутренней сети.

4. **Просмотр прикрепленного скана**:
   - Эндпоинт `/apply/scan/<token>` позволяет заявителю и методисту просматривать и скачивать прикрепленную скан-копию непосредственно в браузере.

## 🛠 Технологический стек

- **Бэкенд**: Python 3.11+, Flask 3.1.2
- **База данных**: MySQL / MariaDB (через SQLAlchemy 3.1 и PyMySQL)
- **Формы и валидация**: Flask-WTF, WTForms, email-validator
- **Генерация документов**: docxtpl (Jinja-шаблонизация файлов `.docx`), python-docx
- **Фронтенд**: HTML5, Vanilla JavaScript (маски ввода, динамическое добавление строк слушателей и программ, валидация), TomSelect, локальные шрифты Manrope

## ⚙️ Установка и запуск

### 1. Клонирование и настройка виртуального окружения
```bash
python -m venv .venv
# Активация:
# Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Linux / macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Конфигурация окружения (.env)
Создайте файл `.env` в корне проекта на основе `.env.example`:
```env
FLASK_APP=run.py
DATABASE_URL=mysql+pymysql://user:password@localhost/dbname?charset=utf8mb4
SECRET_KEY=your-secure-random-secret-key
```

### 3. Применение миграций базы данных
```bash
flask db upgrade
```

### 4. Запуск сервера разработки
```bash
python run.py
```
Сервис доступен по адресу: `http://127.0.0.1:5000`

## 🗄 Управление миграциями базы данных (Flask-Migrate)

В проекте настроена версионная система миграций на базе Alembic. Все изменения структуры таблиц (добавление колонок, индексов, новых сущностей) хранятся в каталоге `migrations/versions/`.

### Основные команды:

- **Применить все актуальные миграции к базе данных:**
  ```bash
  flask db upgrade
  ```
  *(Выполняется при первоначальном развертывании или после получения обновлений из репозитория)*

- **Создать новую миграцию после изменения моделей в коде:**
  ```bash
  flask db migrate -m "add_field_name_to_table"
  ```
  *Alembic автоматически сравнит ваши модели Python в `app/models/` с реальной базой данных и сгенерирует новый файл миграции в `migrations/versions/`.*

- **Посмотреть текущую примененную версию базы данных:**
  ```bash
  flask db current
  ```

- **Посмотреть историю всех миграций:**
  ```bash
  flask db history
  ```

- **Откатить последнюю миграцию (если понадобилось отменить изменения):**
  ```bash
  flask db downgrade
  ```

## 🌐 Настройка Apache для двух сайтов (Публичный и Внутренний)

Сервис сконфигурирован для одновременного обслуживания двух сайтов через Apache Reverse Proxy:
1. **Публичная часть** (`192.168.1.21:8009` / внешний интернет-домен) — подача заявок организациями.
2. **Внутренняя часть для сотрудников** (`http://contractmaker.umcgochs.local`) — реестр заявок, детальный просмотр, скачивание docx и сканов.

Готовый конфигурационный файл находится в `apache_contractmaker.conf`.
Для активации в Apache:
```bash
sudo a2enmod proxy proxy_http headers rewrite
sudo cp apache_contractmaker.conf /etc/apache2/sites-available/contractmaker.conf
sudo a2ensite contractmaker.conf
sudo systemctl reload apache2
```
